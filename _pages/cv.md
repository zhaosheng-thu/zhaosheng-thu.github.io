## Research Experiences
### Avatar Facial Expressions
- *April 2023 -- December 2023*
- *Research Assistant at Tsinghua University, Beijing, China (Advisor: [Xin Yi](https://scholar.google.com/citations?hl=en&user=7Uy9RVYAAAAJ))*
- Keywords: HCI, social computing, blendshape, uncanny valley.
- My works include:
  - Implementing VR face2face chat using TCP-based socket programming and the [Oculus SDK](https://github.com/oculus-samples/Unity-Movement), designing UI to allow users to adjust blendshapes themselves.
  - Designing both qualitative and quantitative research methods based on interviews and questionnaires.
  - Leading experimenter in user research experiments and conducting data analysis.
- This project is currently in the stage of paper writing, and we'll submit it to [ISMAR'24](https://www.ismar.net/2024/)(TVCG'24). Code [here](https://github.com/zhaosheng-thu/AvatarFacial).

### VisionSpin Authentication
- *September 2023 -- Present*
- *Research Assistant at Tsinghua University, Beijing, China (Advisor: [Xin Yi](https://scholar.google.com/citations?hl=en&user=7Uy9RVYAAAAJ))*
- Keywords: HCI, authentication, biometric, security.
- My works include:
  - Project leader, proposing the current authentication framework based on drawing a 3x3 unlock pattern by eye gaze, then using the entered password pattern and behavioral biometrics for authentication.
  - Using Unity to build the experiment platform, which can extract segments of eye and head movements.
  - A two-factor framework of authentication by machine learning, using SVM, KNN, RF, MLP, and ResNet, to implement the classification of behavior biometrics during saccades and fixations of eye movements.
- Code [here](https://github.com/ZhuJunray/srt_vr_auth). We are conducting long-term experiments and the paper work, preparing to submit it to [Ubicomp'24](https://dl.acm.org/conference/ubicomp).
