Human memory datasets

Every dataset used to build a single model of memory behaviour, placed on three axes: how long the memory is held, what the task asks, and what kind of measurement is released. Each card shows the task as drawn in the original paper, the metric that dataset's field uses (what it means, how it is computed, which direction is better), the strongest released models on it, and the unified model.
