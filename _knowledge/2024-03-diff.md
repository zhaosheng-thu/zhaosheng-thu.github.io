### Here are some recent works related to the topic " Diffusion 3D (multi-view) Generation "

#### [DREAMFUSION: TEXT-TO-3D USING 2D DIFFUSION](https://arxiv.org/pdf/2209.14988.pdf)
* The groundbreaking use of a 2D-trained diffusion model for 3D generation.
* Motivation: The lack of 3D train set and the difficulty of generating shapes from text.
* Proposing a novel loss function called "probability density distillation":
<div style="text-align: center;">
  <img src="/_knowledge/diff/Dreamfusion.jpeg" style="width: 85%;">
</div>

* Diffusion is frozen, and the loss is used for backpropagation updates of the MLP in NeRF.
<div style="text-align: center;">
  <img src="/_knowledge/diff/SDS_.jpeg" style="width: 85%;">
</div>

* Open source, have tested it, and the **consistency** for generating different viewpoints in 3D is very **poor**.

#### [DMV3D: Denoising Multi-View Diffusion using 3D Large Reconstruction Model](https://arxiv.org/abs/2311.09217)

* Similar to DreamFusion, the prototype is structured by Nerf + 2D diffusion
* Utilizing multi-view image tokens as the keys (K) and values (V) in cross-attention to direct the denoising process of the Transformer.
<div style="text-align: center;">
  <img src="/_knowledge/diff/DMV3D.jpeg" style="width: 85%;">
</div>

* Con: Require input of camera poses and multiple views.
* Not yet open-sourced, but from the res of the paper we can find that DMV3D generates with **missing details**.

#### [SyncDreamer: Generating Multiview-consistent Images from a Single-view Image](https://arxiv.org/pdf/2309.03453.pdf)

* This pipeline synchronously denoises a target view x(n)t by utilizing a multi-view noise predictor. It constructs spatial and view frustum feature volumes from noisy target views x(1:N)t. Multi-view Diffusion (just duplicate the initial dm N times and denoise them sync):
<div style="text-align: center;">
  <img src="/_knowledge/diff/mvdiffusion.jpg" style="width: 75%;">
</div>

* These volumes, along with input view y and viewpoint difference Δv(n), are processed by a UNet initialized from <i>Zero123</i>. New depth-wise attention layers extract features from the view frustum feature volume. The output of the UNet denoises x(n)t to yield x(n)t−1.
<div style="text-align: center;">
  <img src="/_knowledge/diff/SyncDreamer.png" style="width: 85%;">
</div>

* Highly consistency within different viewpoints because of the Depth-wise attention. We can understand that for each feature block in the UNet, a depth-wise attention layer is used to serve K and V, guiding the learning of UNet feature blocks (serve Q) based on depth information.

* The spatial depth attention layer is constructed from all target views, ensuring the consistency of features.

#### [MVDREAM: MULTI-VIEW DIFFUSION FOR 3D GENERATION](https://arxiv.org/pdf/2308.16512.pdf)

* Similar to <i>SyncDreamer</i>, utilizing the multi-view diffusion model to denosing multi view latent representation. 
* Different from <i>SyncDreamer</i>, MVDeram proposed the multi-view 3D attention.
<div style="text-align: center;">
  <img src="/_knowledge/diff/multi-view-atte.png" style="width: 70%;">
</div>

* Using the pre-trained modified model with camera poses as prior for SDS loss and nerf. Adding the residual of camera embedding with time embedding as guidance.
* Tested, **consistency** is good, but lacking in **detail**.

#### [TOSS: HIGH-QUALITY TEXT-GUIDED NOVEL VIEW SYNTHESIS FROM A SINGLE IMAGE](https://arxiv.org/pdf/2310.10644.pdf)

* Similar to Zero123, single image to multi view novel images
* Using the original image and camera embeddings as the keys and values for cross-attention to guide the UNet.

### <b>Conclusion:</b>
These are the recent papers on multi-view diffusion generation in the top three CV conferences/arXiv in the past several months. It can be observed that a framework guided by prompt semantics has not yet been proposed. Issues such as achieving more efficient and reliable control over viewpoint/depth, reducing deformation and semantic discontinuity remain to be addressed.
