# EmoBlend:A platform for face-to-face communication in VR

**[The repository](https://github.com/zhaosheng-thu/AvatarFacial)** has implemented some novel interaction methods in VR using the SDK Movement.

## Scenes:

I utilized the official SDK for [Oculus Movements](https://github.com/oculus-samples/Unity-Movement) and incorporated several features:

1. **VR World Playback**: Implemented the ability to replay VR world experiences by reading previously recorded data and decoding audio stored in WAV files. This allows for a mirror-like review of past experiences.

2. **Face-to-Face Communication**: Enabled face-to-face communication within the VR world, allowing interaction between users with multiple VR devices in a virtual environment.

3. **Facial blendshape Fine-Tuning multiplier**: Designed a blendshape multiplier, enabling changes in the amplitude of different facial blendshapes. Additionally, a Gaze Cursor was added, responding to your gaze direction.

4. **Virtual Cinema**: Created a virtual cinema within the VR world, providing users with a cinematic experience.
